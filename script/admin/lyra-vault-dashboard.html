How the columns are derived

  • Vault balance is balanceOf(Vault) on the source chain via Multicall3. Derive pool is poolLockedAmounts(connectorPoolIds(connector)) on the Derive hook (lyra) or Controller (lyra-old). A triangle marks a gap above 0.5%.
  • v3 type is custom LZ for HYPE, kHYPE, FXRP, HEMIBTC, SOL and JITOSOL, otherwise native. SOL and JITOSOL have no vault yet, so they do not appear.
  • Time to L1 probes the token contract on its chain: LayerZero OFT (oftVersion / token / sharedDecimals), OP Stack bridged token (remoteToken / l1Token + l2Bridge), Arbitrum gateway token (l1Address), custom canonical token (bridge(), e.g. Lido wstETH), Circle CCTP (known USDC addresses), issuer-minted (masterMinter, Coinbase). Tokens with no on-chain marker use a curated table (tagged manual). Custom-LZ tokens are always instant (tagged rule). Anything estimated under 30 minutes is instant; canonical rollup withdrawals are ~7 days.
  • Value uses DefiLlama current prices for the exact chain and address, falling back to the L1 address of the same symbol.
  • Kelp moved rsETH / wrsETH bridging from LayerZero to Chainlink CCIP after the April 2026 exploit. Both routes are under 30 minutes, so the classification is unchanged.
